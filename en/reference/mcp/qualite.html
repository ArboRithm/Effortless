Quality and drift ​

Drift between code and tasks, project validation and repair, installed safeguards.

confinement_hook_install ​

effortless_confinement_hook_install — Stability: beta · no project

Installs the PreToolUse hook that confines sub-agents; it extends .claude/settings.json and never replaces it.

💬 You ask your agent

« Install the hook that confines sub-agents in this project. »

→ The agent callseffortless_confinement_hook_install

No parameters.

drift_check ​

effortless_drift_check — Stability: stable · story

Detects drift: modified code files (git, in the project and in every stack that has its own repository) while no task is Doing. Also reports whether the anti-drift hook is installed. Read-only.

💬 You ask your agent

« Is there modified code while no task is in progress? »

→ The agent callseffortless_drift_check

No parameters.

drift_hook_install ​

effortless_drift_hook_install — Stability: stable · no project

Installs the anti-drift git pre-commit hook (refuses to commit code without a Doing task) on the project repository and on every stack that has its own repository. Refuses to overwrite a foreign pre-commit hook.

💬 You ask your agent

« Install the anti-drift pre-commit hook on this repository. »

→ The agent callseffortless_drift_hook_install

No parameters.

foyer_registry ​

effortless_foyer_registry — Stability: beta · project

Registry of the marked foyers of the production code, with its blind spot (files without a marker, public functions outside any foyer). Two modes: write_page absent or true writes the sealed page under the declared pages_dir and returns its path; write_page false returns the body under "body" without writing anything.

💬 You ask your agent

« Generate the production code's focal-point registry page. »

→ The agent callseffortless_foyer_registry
  • write_page = true
NameTypeRequiredDescription
write_pagebooleannoIf true (default), writes the sealed page under the declared pages directory; false returns the content under body and writes nothing.

health_repair ​

effortless_health_repair — Stability: beta · project

Diagnoses the registry and repairs whatever can be fixed without a decision (forgotten closures). Without apply, only reports what it would do.

💬 You ask your agent

« Diagnose the registry and apply the decision-free repairs, such as forgotten closures. »

→ The agent callseffortless_health_repair
  • apply = true
NameTypeRequiredDescription
applybooleannoIf true, actually applies the repairs; absent or false only announces what would be done and changes nothing.

validate_project ​

effortless_validate_project — Stability: stable · project

Audits the project registry (epics, stories, tasks) and returns the anomalies ranked by severity. Refuses a folder that is not a valid Effortless project. Read-only.

💬 You ask your agent

« Audit the project registry and show me the anomalies by severity. »

→ The agent callseffortless_validate_project

No parameters.
