bqo_ask ​

effortless_bqo_ask — Stability: stable · project

Records a big open question (BQO) at the project level.

💬 You ask your agent

« Record this big open question at project level: "Should we migrate authentication to OAuth2?" »

→ The agent callseffortless_bqo_ask
  • question = Should we migrate authentication to OAuth2?
NameTypeRequiredDescription
questionstringyesText of the big open question (BQO) to record at project level. Required.

bqo_graduate ​

effortless_bqo_graduate — Stability: stable · project

Promotes a BQO into an EXISTING epic (epic_id): the question is copied there and its status becomes graduated. Does not create an epic.

💬 You ask your agent

« Graduate big open question Q-02 into the existing epic 012. »

→ The agent callseffortless_bqo_graduate
  • question_id = Q-02
  • epic_id = 012
NameTypeRequiredDescription
question_idstringyesId of the BQO to promote into an epic. Required.
epic_idstringyesId of the existing target epic that inherits the BQO. Required.

decision_add ​

effortless_decision_add — Stability: stable · story

Adds a decision (ADR) to a story. Returns the id (DEC-NN).

💬 You ask your agent

« Record the decision "SQLite rather than Postgres" on story 003 of epic 012, in phase O-analyse. Context: the app stays single-machine. Decision: use SQLite. Consequence: no database server to install. Rejected alternative: Postgres. »

→ The agent callseffortless_decision_add
  • epic_id = 012
  • story_id = 003
  • title = SQLite rather than Postgres
  • context = The app stays single-machine.
  • decision = Use SQLite.
  • consequences = No database server to install.
  • rejected_alternatives = Postgres
  • phase = O-analyse
NameTypeRequiredDescription
epic_idstringyesId of the epic that holds the story. Required.
story_idstringyesId of the story that receives the decision. Required.
titlestringyesTitle of the decision. Required.
contextstringyesContext of the decision. Required.
decisionstringyesThe decision made. Required.
consequencesanyyesConsequences: array of strings, or a multi-line string with one entry per line. Required.
rejected_alternativesanyyesRejected alternatives: array of strings, or a multi-line string with one entry per line. Required.
phasestringyesOPALE phase the decision belongs to, as a workflow phase id (default workflow: O-analyse, P-cadrage, A-specs, L-plan, E-execute). Required.

phasestringyesOPALE phase the question belongs to, as a workflow phase id (default workflow: O-analyse, P-cadrage, A-specs, L-plan, E-execute). Required.
