Status and steering ​

Read the project state, what is waiting, the work mode, the sessions.

attention ​

effortless_attention — Stability: beta · project

What is waiting for you: the current work, the open points (questions, recipes to verify, orphan tasks, critical anomalies, git, delivery, drift), the statistics and the queue. An unreadable source is named in skipped. Read-only.

💬 You ask your agent

« What is waiting for me on this project? Show me what's in progress and the open points. »

→ The agent callseffortless_attention

No parameters.

features ​

effortless_features — Stability: beta · no project · usable before any project

Lists the versioned feature registry (effortless_* tools) and, only with write_doc: true, regenerates docs/FEATURES.md under the project root and refreshes the derived section of AGENTS.md and the import in CLAUDE.md (between markers).

💬 You ask your agent

« List the Effortless features available. »

→ The agent callseffortless_features
NameTypeRequiredDescription
write_docbooleannoIf true, regenerates docs/FEATURES.md and refreshes the derived sections of AGENTS.md and CLAUDE.md under the project root; default false (list only, nothing written).

mode_set ​

effortless_mode_set — Stability: stable · project

Changes the project work mode (full / semi-auto / tutore) and persists it in effortless.json.

💬 You ask your agent

« Switch the project to semi-auto mode. »

→ The agent callseffortless_mode_set
  • mode = semi-auto
NameTypeRequiredDescription
modestringyesTarget work mode: full, semi-auto or tutore. Required.

mode_show ​

effortless_mode_show — Stability: stable · project

Current work mode of the project (full / semi-auto / tutore) with its description.

💬 You ask your agent

« Which working mode is the project in? »

→ The agent callseffortless_mode_show

No parameters.

modules ​

effortless_modules — Stability: beta · project

The project's declared modules: identity (path, languages, model, norms), git and version (own or root repository, branch, modified files, last commit, last tag, version from its files), delivery (build, artifacts), work (epics, stories, tasks cited by commits on its path over 90 days). Read-only.

💬 You ask your agent

« Show me the project's modules: version, git state and ongoing work for each. »

→ The agent callseffortless_modules

No parameters.

effortless_project_tree — Stability: stable · project

Full tree of the project (epics → stories → statuses). Read-only.

💬 You ask your agent

« Show me the project tree: epics, stories and statuses. »

→ The agent callseffortless_project_tree

No parameters.

secondbrain_sync ​

effortless_secondbrain_sync — Stability: stable · project

Synchronizes the project state (active OPALE phase + decisions/tasks) to the SecondBrain Vault: updates context.md + timestamped archive. Clear error if the vault cannot be found.

💬 You ask your agent

« Sync the project's state to my Kessho memory. »

→ The agent callseffortless_secondbrain_sync
NameTypeRequiredDescription
createbooleannoCréer le projet Kessho s'il n'existe pas (rattaché à ce dépôt). À ne passer qu'avec l'accord de l'utilisateur : le refus kessho:projetAbsent le demande.

session_summary ​

effortless_session_summary — Stability: beta · project

Writes the summary of the current session (what it did, as observed) into .effortless/sessions/, local to this machine. Refused when empty.

💬 You ask your agent

« Save this session's summary: "CSV export fixed, parser tests written". »

→ The agent callseffortless_session_summary
  • summary = CSV export fixed, parser tests written
NameTypeRequiredDescription
summarystringyesWhat the session did, as observed, in a few sentences; an empty value is refused. Required.

sessions ​

effortless_sessions — Stability: beta · project

Session history, most recent first: Kessho first, otherwise the local sessions. last = the latest session (title, summary); the reason for a fallback is named in skipped. Read-only.

💬 You ask your agent

« Summarize my last working session on this project. »

→ The agent callseffortless_sessions

No parameters.
