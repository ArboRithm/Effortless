Statut et pilotage ​

Lire l’état du projet, ce qui attend, le mode de travail, les sessions.

attention ​

effortless_attention — Stabilité : beta · projet

Ce qui t'attend : l'en-cours, les points ouverts (questions, recettes à vérifier, tâches orphelines, anomalies critiques, git, livraison, dérive), les statistiques et la file. Une source illisible est nommée dans skipped. Lecture seule.

💬 Vous demandez à l’agent

« Qu'est-ce qui m'attend sur ce projet ? Montre-moi l'en-cours et les points ouverts. »

→ L’agent appelleeffortless_attention

Aucun paramètre.

features ​

effortless_features — Stabilité : beta · sans projet · utilisable avant tout projet

Liste le registre de fonctionnalités versionné (tools effortless_*) et, seulement avec write_doc: true, régénère docs/FEATURES.md sous la racine du projet et rafraîchit la section dérivée d'AGENTS.md et l'import de CLAUDE.md (entre marqueurs).

💬 Vous demandez à l’agent

« Liste les fonctionnalités Effortless disponibles. »

→ L’agent appelleeffortless_features
NomTypeRequisDescription
write_docbooleannonSi true, régénère docs/FEATURES.md et rafraîchit les sections dérivées d'AGENTS.md et de CLAUDE.md sous la racine du projet ; défaut false (liste seule, rien n'est écrit).

mode_set ​

effortless_mode_set — Stabilité : stable · projet

Change le mode de travail du projet (full / semi-auto / tutore) et le persiste dans effortless.json.

💬 Vous demandez à l’agent

« Passe le projet en mode semi-auto. »

→ L’agent appelleeffortless_mode_set
  • mode = semi-auto
NomTypeRequisDescription
modestringouiMode de travail cible : full, semi-auto ou tutore. Obligatoire.

modules ​

effortless_modules — Stabilité : beta · projet

Les modules déclarés du projet : identité (chemin, langages, modèle, normes), git et version (dépôt propre ou racine, branche, fichiers modifiés, dernier commit, dernier tag, version de ses fichiers), livraison (build, artefacts), travail (épics, stories, tâches cités par les commits de son chemin sur 90 jours). Lecture seule.

💬 Vous demandez à l’agent

« Montre-moi les modules du projet : version, état git et travail en cours de chacun. »

→ L’agent appelleeffortless_modules

Aucun paramètre.

secondbrain_sync ​

effortless_secondbrain_sync — Stabilité : stable · projet

Synchronise l'état projet (phase OPALE active + décisions/tâches) vers le Vault SecondBrain : maj context.md + archive horodatée. Erreur claire si le vault est introuvable.

💬 Vous demandez à l’agent

« Synchronise l'état du projet vers ma mémoire Kessho. »

→ L’agent appelleeffortless_secondbrain_sync
NomTypeRequisDescription
createbooleannonCréer le projet Kessho s'il n'existe pas (rattaché à ce dépôt). À ne passer qu'avec l'accord de l'utilisateur : le refus kessho:projetAbsent le demande.

session_summary ​

effortless_session_summary — Stabilité : beta · projet

Écrit le résumé de la session courante (ce qu'elle a fait, constaté) dans .effortless/sessions/, local au poste. Refusé si vide.

💬 Vous demandez à l’agent

« Enregistre le résumé de cette session : « Export CSV corrigé, tests du parseur écrits ». »

→ L’agent appelleeffortless_session_summary
  • summary = Export CSV corrigé, tests du parseur écrits
NomTypeRequisDescription
summarystringouiCe que la session a fait, constaté, en quelques phrases ; une valeur vide est refusée. Obligatoire.

sessions ​

effortless_sessions — Stabilité : beta · projet

Historique des sessions, plus récentes d'abord : Kessho d'abord, sinon les sessions locales. last = la dernière session (titre, résumé) ; la raison d'un repli est nommée dans skipped. Lecture seule.

💬 Vous demandez à l’agent

« Résume-moi ma dernière session de travail sur ce projet. »

→ L’agent appelleeffortless_sessions

Aucun paramètre.
