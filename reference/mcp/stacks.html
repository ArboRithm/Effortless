scaffold_apply ​

effortless_scaffold_apply — Stabilité : beta · sans projet

Applique un template de scaffold dans un répertoire cible (idempotent, garde anti-traversée).

💬 Vous demandez à l’agent

« Applique le template de scaffold « api-rest » dans le dossier services/billing avec le nom de service « billing ». »

→ L’agent appelleeffortless_scaffold_apply
  • template_id = api-rest
  • target_dir = services/billing
  • variables = {"service_name":"billing"}
NomTypeRequisDescription
template_idstringouiId du template de scaffold (voir effortless_scaffold_list). Obligatoire.
target_dirstringouiRépertoire dans lequel les fichiers du template sont écrits ; les fichiers existants sont laissés intacts et rapportés comme ignorés. Obligatoire.
variablesobjectnonSurcharges des variables du template, sous forme d'objet JSON nom → valeur (défaut : les valeurs propres au template).

stack_add ​

effortless_stack_add — Stabilité : beta · sans projet

Déclare une stack de code (id, chemin, branche), scaffolde codebase/<id>/ et applique le modèle (scaffold_template = model_id) avec ses variables. Les normes des langages déclarés (languages, qui priment sur ceux du modèle) sont posées dans .ai/ndd/ à la racine du projet ; celles qui manquent sont nommées. git: true pour une stack qui a son propre dépôt.

💬 Vous demandez à l’agent

« Déclare une stack « site » dans codebase/site, branche main, avec le modèle node. »

→ L’agent appelleeffortless_stack_add
  • id = site
  • path = codebase/site
  • branch = main
  • scaffold_template = node
NomTypeRequisDescription
idstringouiId de la nouvelle stack (sous-répertoire de codebase/) ; un id vide ou déjà utilisé est refusé. Obligatoire.
pathstringnonChemin de la stack (défaut codebase/<id>/) ; un chemin hors du projet rend la stack externe.
branchstringnonBranche git associée à la stack (optionnelle).
sharedbooleannonIndique si la stack est partagée (défaut false).
scaffold_templatestringnonId du modèle de stack ou du template de scaffold à appliquer à la stack (optionnel) ; il pré-remplit aussi les langages déclarés.
driftbooleannonIndique si la surveillance de dérive est active pour la stack (défaut true).
varsobjectnonValeurs des variables du modèle, sous forme d'objet JSON ; utilisées au rendu de scaffold_template et persistées dans vars de la stack.
gitbooleannonIndique si la stack a son PROPRE dépôt git (défaut false) ; à déclarer pour une stack hors du projet, sinon seul le dépôt du projet est suivi.
languagesarraynonLangages déclarés de la stack. Tableau d'objets {id, version?, ndd?} : id est le langage (par exemple rust), version la version visée, ndd la méta de la norme {id, version, source} où source vaut embedded par défaut. Prime sur le pré-remplissage du modèle.

stack_declare_languages ​

effortless_stack_declare_languages — Stabilité : beta · sans projet

Déclare ou corrige les langages d'une stack. La déclaration remplace la précédente, elle ne fusionne pas. Chaque entrée est un objet {id, version?, ndd?{id, version, source}}. Une liste vide est acceptée et déclare « aucune norme ». Refuse une stack inconnue et une déclaration malformée, entrée par entrée.

💬 Vous demandez à l’agent

« Déclare que la stack app utilise Rust 1.80 et TypeScript 5. »

→ L’agent appelleeffortless_stack_declare_languages
  • stack_id = app
  • languages = [{"id":"rust","version":"1.80"},{"id":"typescript","version":"5"}]
NomTypeRequisDescription
stack_idstringouiId de la stack à corriger ; une stack inconnue est refusée. Obligatoire.
languagesarrayouiLa déclaration COMPLÈTE, qui remplace la précédente ; un tableau vide déclare que la stack n'a aucune norme. Tableau d'objets {id, version?, ndd?} : id est le langage (par exemple rust), version la version visée, ndd la méta de la norme {id, version, source} où source vaut embedded par défaut. Obligatoire.

stack_housekeeping ​

effortless_stack_housekeeping — Stabilité : beta · sans projet

Constate l'entretien déclaré des stacks : ce qui serait purgé, sa taille et pour quel langage. Ne supprime rien par défaut, apply: true est un geste explicite. La politique vit dans languages[].housekeeping de chaque stack. Refuse par leur nom un chemin absolu, remontant, visant une racine réservée (target/release, .git, .effortless, blueprints, src, tests), lien symbolique ou résolu hors de la stack.

💬 Vous demandez à l’agent

« Qu'est-ce qui serait purgé dans la stack app pour libérer de la place ? Ne supprime rien. »

→ L’agent appelleeffortless_stack_housekeeping
  • stack_id = app
  • apply = false
NomTypeRequisDescription
stack_idstringnonId de la stack visée (défaut : toutes les stacks déclarées).
applybooleannonSi true, EXÉCUTE la purge ; absent ou false, constat seul, rien n'est supprimé.

worktree_reintegrate ​

effortless_worktree_reintegrate — Stabilité : beta · sans projet

Réintègre le travail d'un worktree dans le dépôt, si et seulement si la barre mesurée dans ce worktree est verte ; sinon refuse sans rien écrire. Après une fusion réussie, retire le worktree et sa branche (rapportés sous purged) ; keep_worktree: true les conserve.

💬 Vous demandez à l’agent

« Réintègre le worktree ../wt-export dans le dépôt, la barre étant `pnpm test` et `pnpm lint`. »

→ L’agent appelleeffortless_worktree_reintegrate
  • worktree_path = ../wt-export
  • bar = {"test":"pnpm test","lint":"pnpm lint"}
NomTypeRequisDescription
worktree_pathstringnonChemin du worktree à réintégrer ; le moteur n'en crée jamais, il réintègre un arbre que le harnais a déjà posé. À fournir, ou worktree_paths.
worktree_pathsarray<string>nonPlusieurs worktrees, un par dépôt d'un projet composé (le premier est celui du projet) ; la barre est mesurée une fois, puis un merge par dépôt, et un échec partiel est nommé, jamais annulé.
keep_worktreebooleannonSi true, garde le worktree et sa branche fusionnée après une fusion réussie ; défaut false, ils sont retirés (rapportés sous purged).
barobjectouiBarre mesurée DANS le worktree : objet associant un nom (test, lint, typecheck, build) à une commande shell, ou à un objet avec command et éventuellement cwd ou stack ; la réintégration est refusée tant qu'elle n'est pas verte. Obligatoire.
